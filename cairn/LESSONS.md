# Lessons

_Durable, append-only repo lessons (build quirks, testing tricks). Captured at
milestone end, surfaced at plan time. Capped at 50 lines (D-015)._

- 2026-07-18 (M05): assert bspm's *binary* install path (not a source fallback) by checking `dpkg -s r-cran-<lowercased-pkg>` after install.packages(). r2u names binaries r-cran-<name>, and a source compile loads but registers no apt package.
- 2026-07-18 (M05): smoke-test the Quarto CLI on an image that ships no R packages (IP1) with a chunk-free .qmd. Quarto's markdown engine renders via bundled Pandoc and needs no knitr or jupyter. Add an R code chunk only if you first install knitr.
- 2026-07-18 (M07): simulate an r2u mirror outage in the container smoke by blackholing non-Ubuntu apt hosts (`/etc/hosts` → 127.0.0.1) and pointing `options(repos=)` at a dead port to kill bspm's source fallback. apt's `Acquire::Retries` shows as repeated `Ign:/Err:` lines in bspm's `apt-get update`.
- 2026-07-18 (M07): to add a friendly hint on install failure, key on post-install state (is the package still missing?) plus a scoped reachability probe, not apt-error text. Scope the probe to the R package mirrors (drop `*.ubuntu.com/.org`), or an unrelated Ubuntu-archive blip false-fires.
- 2026-07-18 (M08): to run a Windows `.bat` in CI, stub `docker` as a real `.exe` (bare `docker`→`.cmd` chains via goto and never returns), set PATH inside a wrapper `.cmd`, and fake "not installed" with a tool-only dir (the real docker.exe is on the runner's System32).
- 2026-07-18 (M09, used M026): a stub resolving the same config as the code under test gives false coverage, so force the code's own parse to reach the output, then mutate to confirm. A stub answering a looped query must be argument-sensitive and multi-item (M10).
- 2026-07-18 (M09, used M024): ask `docker compose port <svc> <port>` for the real host binding instead of re-deriving it from RS_PORT/.env. It is authoritative across every override mechanism.
- 2026-09-04 (M13): cancelling a workflow run cancels its downstream jobs before their `if:` runs, so a cancelled run shows `cancelled`, never `skipped` — a skip needs a run that completes.
- 2026-09-04 (M13): a matrix `include` leg with several keys is named `job (k1, k2, k3)`; set `name: job (${{ matrix.variant }})` when a script parses job names.
- 2026-09-06 (M015): `docker buildx imagetools create --dry-run` prints the exact index the real create would push. Assert on it before the create, so a bad manifest is refused rather than reported after the tags already moved.
- 2026-09-07 (M016): a job running a repo script against another ref needs two checkouts, the workflow's own ref for the code and the target ref for the write. Only a real dispatch shows the gap.
- 2026-09-07 (M016, used M026): `^[0-9]+$` is not a bound. `10#$n` on 19+ digits wraps negative and inverts the comparison, so bound by digit width, and drive over-wide, zero-padded and widest-in-range.
- 2026-10-21 (M019): GitHub sets an artifact's `expires_at` 0–1 s short of `created_at` + `retention-days`, so a criterion on expiry needs a stated tolerance; download-artifact's `pattern` (minimatch) expands `{a,b}` braces and, matching nothing, downloads nothing with no error — a count check after it must catch the miss.
- 2026-10-21 (M020, used M026): a script whose answer a workflow step captures with `$(...)` swallows its own `::warning::` lines into that answer; have it write the answer to a file named by an argument and keep stdout for the run log.
- 2026-11-05 (M023): a launcher seam branch that skips a wait hides it from the harness, so print a marker there. To run the real `read`, use Python `pty.fork` and poll `waitpid(WNOHANG)` before and after a key: `script` with a piped `sleep` shows only the pipe's timing, on both paths.
- 2026-11-05 (M023, used M026): `launchers.yml` and `lint.yml` run only on pull requests and this Mac has no `cmd`, `pwsh`, or `shellcheck`. To see Windows checks fail before a merge approval, get the user's yes, then push a temporary branch with those workflows set to `on: push` and a step that plants defects and runs the harness.
- 2026-11-05 (M023): `docker compose up -d --wait` redraws in place in a terminal (net 4 rows on Compose 5.6.1), so a line printed before it stays on a 24-row window. Measure before claiming that it scrolls text away.
- 2026-11-05 (M024): a launcher test whose requested and bound ports match cannot catch a broken Compose query, because the launcher's fallback gives the same port. Set the port in a Compose override so only Compose knows it.
- 2026-11-05 (M024, used M026): with Docker Desktop off, every planted-defect run still exits 1, so a plant counts as red only when its output names the expected `FAIL:` check. Exit status alone would pass a run that tested nothing.
- 2026-11-05 (M025, used M026): an `rm` in a later Dockerfile `RUN` only hides files, so the download does not shrink. Remove them in the `RUN` that installs them, and list the layers of a `docker save` to confirm. The layer sum from `docker buildx build --output type=oci,dest=x.tar` matched Docker Hub's size to within 0.1 MB.
- 2026-11-05 (M025): with a broken dependency, bspm's next apt run removes `rstudio-server` to settle it, and the bundled Quarto goes too. A package check after an install reads the repaired state, so run `apt-get check` before the first install.
- 2026-11-05 (M025): Copilot's language server answers `initialize` with its native `runtime.node` folder gone, because it loads that module later. A check must also `require` the module, or a missing folder passes.
- 2026-11-05 (M026): `jq` reads every JSON document in its input, so a valid manifest followed by junk prints a size before jq fails, and `$(...)` drops the failure. Read a registry answer with `jq -s` and require exactly one document.
- 2026-11-05 (M026): to measure a pull request build's download size, run `docker/build-push-action` again with the same arguments and `outputs: type=oci,dest=<file>`. The builder's cache serves it in about 3 seconds, and its layer sum matched Docker Hub's 723.1 MB.
