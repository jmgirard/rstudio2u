## Highlights

- **Single Dockerfile** for all tags. Pick the base with `--build-arg UBUNTU_VERSION=24.04|26.04` instead of maintaining separate `noble`/`resolute` Dockerfiles.
- **RStudio version auto-detects** to the newest stable release at build time (still overridable via `--build-arg RSTUDIO_VERSION=…`), so no more manual version bumps.
- **s6-overlay upgraded v2.1.0.2 → v3.2.3.0** (the old v2 was end-of-life), now with SHA256 verification of the downloads.
- **Double-click launchers** (`start_*` / `stop_*` for macOS, Windows, Linux) so non-technical users can run the server without the command line.
- **Work now persists** across restarts, image updates, and pruning via a named `rstudio_home` volume.
- **Smaller image (~210 MB)** by removing a duplicate Pandoc (RStudio already bundles it) and RStudio's developer-only JS debug symbol maps.

## Reliability fixes

- Passing `-e VAR=…` now actually reaches R (`Renviron.site`) — `R_HOME` is resolved correctly on the r2u base.
- arm64 keeps working with auto-detected RStudio versions (falls through to the versioned download URLs, which have an arm64 fallback).
- A custom `USERID` no longer loses passwordless sudo, so bspm keeps working (grant is now group-based).
- Added a `HEALTHCHECK`; the launchers use `docker compose up --wait` to know when RStudio is genuinely ready.

## CI / maintainability

- New GitHub Actions workflow builds and pushes multi-arch (amd64 + arm64) images for both tags.
- A weekly scheduled build now genuinely refreshes R, RStudio, Pandoc, and Quarto (rebuilds without cache) instead of silently reusing stale layers.
- Dockerfile reorganized into clear sections with fewer, consolidated layers.

## Security & docs

- Documented the security model: the image is intentionally root-capable (bspm requires it); keep it bound to localhost and avoid exposing it or running privileged.
- README refreshed: accurate tag table, quick-start launcher instructions (incl. the macOS Gatekeeper first-run note), and how to move files in/out of the volume.

**Verified:** builds and boots on both amd64 and arm64 — RStudio serves, PAM login and passwordless sudo work, env vars reach R, bspm binary installs and passwordless apt work, and work survives destroying/recreating the container.
