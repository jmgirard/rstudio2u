Adds reproducibility features and documentation aimed at instructors, students, and derivative-image authors.

## New features

- **Immutable image tags for reproducibility.** CI now publishes date-stamped (`<variant>-YYYY-MM-DD`) and RStudio-version (`<variant>-<version>`) tags in addition to the moving `latest`/`noble`/`resolute` tags, so a course can pin a frozen, identical environment. The build pins `RSTUDIO_VERSION` so the version tag matches the image contents.

## Documentation

- **Adding R Packages**: interactive bspm installs plus a derivative `Dockerfile` pattern for preinstalling a course/lab package set.
- **Reproducibility**: how to pin immutable tags, plus an renv note for project-level reproducibility.
- **FAQ / Troubleshooting**: Docker not running, changing the port, updating, resetting, Apple Silicon, and login.
- Status/pulls/size/license **badges** and a **CITATION.cff** (with ORCID) for the "Cite this repository" button.
