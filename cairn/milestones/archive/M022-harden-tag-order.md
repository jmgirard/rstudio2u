# M022: Harden the tag-order check

**Status:** done (2026-10-20, PR #33 https://github.com/jmgirard/rstudio2u/pull/33)

**Goal:** A failed registry read fails a publish leg only after 3 reads of that ref fail, and a tag stamped later than the current UTC time fails the leg instead of being left out with a warning.

**Outcome:** `.github/tag-order.sh` reads a ref again after a failed read (non-zero exit, stderr other than the buildx not-found line for that ref), up to 3 reads, pausing `TAG_ORDER_RETRY_DELAY` seconds (default 10; set but not 1 to 3 digits exits 1). Failed reads 1 and 2 log a `::notice::` with the ref, read number and cause; read 3's cause goes in the `::error::`. A not-found or exit-0 answer ends the loop. Before any read it takes the time from `TAG_ORDER_NOW` (set, empty included) or `date -u +%Y-%m-%dT%H:%M:%SZ`, logs it with its source, and exits 1 on a bad time or a run stamp later than it. A tag stamped later than the time is unsettled (exit 1, no output file). Registry error text has `%` escaped and CR dropped before it reaches a workflow command. The header holds the hand re-point command; `docker.yml` comments and `test_mode` description, and the DESIGN.md tag-order bullet, describe the retry, the clock rule and their bounds. `scripts/tests/test_tag_order.sh` adds `sleep`, `date` and per-read failure stubs and cases 18a-21b (176 checks). Test-mode dispatch 39540657484 ran both publish legs with the real clock. User-visible change: a brief Docker Hub read failure no longer fails the weekly publish, and a tag stamped in the future now fails that variant's publish (date and version tags included) until the clock passes the stamp or the tag is re-pointed, where before it froze only that tag with a warning.

**Decisions:** none. The plan gate chose a retry loop inside the script over `scripts/retry.sh` (a not-found must end the loop), an exact clock comparison with no skew margin, failing the leg on a future stamp, and failing on a run stamp later than the clock. The user declined pinning buildx; DESIGN.md records that a reworded not-found line would fail every publish.

All six criteria verified fresh; AC5 completed on PR #33's checks. No amendments. Graduated the candidate rows "Refuse tag stamps later than the clock" and "Retry the tag-order registry reads".
