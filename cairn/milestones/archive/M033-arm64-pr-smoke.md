# M033: Smoke-test arm64 in the PR lane

**Status:** done (2026-11-05, PR #55 https://github.com/jmgirard/rstudio2u/pull/55)

**Goal:** Build, boot, and size-check each committed variant's arm64 image on a native arm64 runner in `pr-ci.yml`, so an arm64-only break fails the pull request instead of the publish.

**Outcome:** `pr-ci.yml`'s `build-smoke` job is four matrix entries, `build-smoke (<variant>, <arch>)` for noble and resolute on amd64 (`ubuntu-latest`) and arm64 (`ubuntu-24.04-arm`), with `runs-on: ${{ matrix.runner }}`. A first step, "Check the runner is <arch>", derives the expected `uname -m` from `arch` with a `case`, prints `runner uname -m: <got> (the <arch> job expects <want>)`, and exits 1 on a mismatch. Then each job builds `linux/<arch>` with the `<variant>-<arch>` gha cache scope, runs `smoke-test.sh`, exports an OCI archive, and runs `image-size.sh --from-oci <variant> <arch>`, so arm64 growth past a variant's limit now fails the PR. README:21, DESIGN's graduation paragraph, size-limit bullet, and arm64-runner Known issue (an outage now blocks image PRs), and the comments in `image-size.sh`, `image-size-limits`, and `smoke-test.sh` say the PR lane checks both architectures. User-visible: a PR that changes the image is now checked on amd64 and arm64 before it merges. No image change, so no release (D-005).
